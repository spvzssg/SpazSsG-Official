## OFFICIAL LOGO DESCRIPTION

The official Spaz SsG logo is a dynamic, cinematic design featuring:

- **Primary Text**: Bold, metallic lettering reading "SPAZ" over "SSG"
- **Text Styling**: Thick, modern sans-serif with angular, energetic cuts
- **Text Fill**: Metallic silver/white with subtle texture and depth
- **Crown Element**: Stylized crown positioned above the "SPAZ" text
- **Crown Style**: Geometric, futuristic design with sharp points
- **Energy Effects**: Electric cyan (#00DDF5) and burnt orange (#FF791D) neon glow outlines
- **Atmospheric Effects**: Teal/cyan smoke and particle effects on left side
- **Fire Effects**: Orange and red fire-like energy discharge on right side
- **Background**: Transparent (can overlay on any background)
- **Lighting**: 3D-rendered appearance with dramatic cinematic lighting
- **Overall Aesthetic**: High-energy, dynamic, modern, music-industry professional

## LOGO USAGE GUIDELINES

### Where to Use

✅ **DO Use**:
- App launch/splash screen
- Home screen header
- Navigation bar (when appropriate)
- About/Profile section
- Loading screens
- Promotional materials
- App store screenshots
- Welcome screens
- Brand identity screens

### Where NOT to Use

❌ **DON'T Use**:
- As loading indicator spinner
- At extremely small sizes (< 100px)
- Distorted or stretched
- Recolored without approval
- Recreated or redesigned
- In a way that changes its meaning

### Sizing Rules

- **Minimum Size**: 100px width (use small version at this size)
- **Recommended Size**: 200px-600px width for header use
- **Hero Display**: 1200px-1600px width for full-screen features
- **Always Maintain**: Original aspect ratio (no stretching)

### Background Usage

- **On Dark Backgrounds**: Logo displays naturally (dark background in design)
- **On Light Backgrounds**: Use inverted variant (if created) or add subtle dark shadow
- **On Colored Backgrounds**: Ensure sufficient contrast (minimum 3:1 ratio)

### Padding & Spacing

- **Minimum Clear Space**: 20% of logo width on all sides
- **Don't Overlap**: Logo should never be overlapped with other elements
- **Breathing Room**: Allow space around logo for visual impact

### Animation & Effects

- **Subtle Motion**: Gentle fade-in on app launch is acceptable
- **No Distortion**: Never morph, rotate, or heavily animate
- **Glitch Effects**: Acceptable if matches brand energy (use sparingly)
- **Scale Animation**: Gentle scale transitions are OK

## IMPLEMENTATION IN MOBILE APP

### React Native/Expo Integration

**Import Logo Component**:
```typescript
// types/branding.ts
export type LogoSize = 'sm' | 'md' | 'lg' | 'hero';

// components/Logo.tsx
import { Image } from 'react-native';

interface LogoProps {
  size?: LogoSize;
  style?: any;
}

export function SpazSsGLogo({ size = 'md', style }: LogoProps) {
  const logoMap = {
    sm: require('@/assets/branding/logo/spaz-ssg-logo-sm.png'),
    md: require('@/assets/branding/logo/spaz-ssg-logo-md.png'),
    lg: require('@/assets/branding/logo/spaz-ssg-logo-lg.png'),
    hero: require('@/assets/branding/logo/spaz-ssg-logo-hero.png'),
  };

  const dimensionsMap = {
    sm: { width: 200, height: 120 },
    md: { width: 400, height: 240 },
    lg: { width: 600, height: 360 },
    hero: { width: 1200, height: 720 },
  };

  return (
    <Image
      source={logoMap[size]}
      style={[dimensionsMap[size], style]}
      resizeMode="contain"
    />
  );
}
```

**Usage in Screens**:
```typescript
// screens/HomeScreen.tsx
import { SpazSsGLogo } from '@/components/Logo';

export function HomeScreen() {
  return (
    <View style={styles.container}>
      <SpazSsGLogo size="hero" style={styles.logo} />
      {/* Rest of content */}
    </View>
  );
}
```

**Usage in Navigation**:
```typescript
// Set header logo
options={{
  headerLeft: () => <SpazSsGLogo size="sm" />,
}}
```
